# Real-Time-Face-Emotion-Detection-
A real-time facial emotion recognition system built with Python, OpenCV, and DeepFace. 

## Technologies Used
* Python, OpenCV, DeepFace, TensorFlow, Jupyter Notebook

## Emotions Detected
* Happy, Sad, Angry, Fear, Surprise, Neutral, Disgust

# Working Process: 
* Capture video frames from the webcam.
* Detect faces in each frame.
* Analyze facial expressions using DeepFace.
* Predict the dominant emotion.
* Display the detected emotion and face outline in real time.
